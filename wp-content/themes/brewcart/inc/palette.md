# BrewCart Design System

## Color Palette

| Token | Hex | Use |
|---|---|---|
| `--espresso` | #2B1B14 | Primary text, header/footer bg |
| `--espresso-light` | #4A3226 | Secondary dark surface |
| `--coffee-brown` | #6F4E37 | Primary buttons, links |
| `--amber` | #C68B3C | Accent, CTAs, hover states, badges |
| `--amber-light` | #E8B96A | Accent hover / highlights |
| `--cream` | #FBF3E7 | Page background |
| `--latte` | #F1E3CE | Card/section background |
| `--charcoal` | #33291F | Body text |
| `--charcoal-soft` | #6B5D4F | Muted text |
| `--success` | #4C7A4C | Success states |
| `--error` | #B4483A | Error states |
| `--white` | #FFFFFF | Card surfaces |

## Typography

- Headings: "Fraunces" (serif, premium/display) — Google Fonts, free
- Body: "Inter" (sans-serif, clean) — Google Fonts, free
- Base size: 16px, scale 1.25 (major third)

## Radii & Shadows

- `--radius-sm`: 8px, `--radius-md`: 16px, `--radius-lg`: 24px, `--radius-pill`: 999px
- `--shadow-soft`: 0 4px 20px rgba(43,27,20,0.08)
- `--shadow-hover`: 0 12px 32px rgba(43,27,20,0.16)
